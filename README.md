# UPC Acceso Vehicular Frontend

Frontend web para la administración del parqueadero de motos.

## Requisitos

- Node.js y npm
- API .NET ejecutándose en `http://localhost:5028` (o define `VITE_API_URL`)

## Instalar y ejecutar

```powershell
npm install
Copy-Item .env.example .env.local
npm run dev
```

## Compilar

```powershell
npm run build
```
